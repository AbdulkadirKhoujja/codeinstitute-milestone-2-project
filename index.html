How to Play

Repeat the signal. Protect your lives.

  1. Press start and watch the tile sequence carefully.
  2. Click or tap the tiles in the same order.
  3. Complete a round to score points and unlock a longer pattern.
  4. Make a mistake and you lose a life. The game ends when all lives are gone.
  5. Keyboard players can tab to a tile and press Enter or Space.

About

Built for focused memory play

Pixel Quest Memory Game is a browser game created to help players practise pattern recognition, short-term memory, and quick recall in a retro arcade style.

This project uses original HTML, CSS, and JavaScript written for Code Institute Project 2. No external game code is included.
